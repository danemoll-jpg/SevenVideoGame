# Atmosphere — the reusable world look (Kyle's fog/glow mood)

Every world starts from this setup (rule in `CLAUDE.md` → "World look"). Reference: `Art/Reference/kyle_world_mood.jpg`
— dark foreground silhouettes, a bright glowing misty distance, strong ground fog, soft lights inside the fog, huge
structures fading into the haze. Strictly monochrome: every knob is a brightness, never a colour.

## What it is made of
| Piece | Path | Job |
|---|---|---|
| Prefab | `Unity/Assets/Atmosphere/Atmosphere.prefab` | Drop into a scene. Holds the `Atmosphere` component, the global post-process Volume, a back light (from the bright distance toward the viewer), a soft front fill, and `Glow*` children. |
| Component | `Unity/Assets/Scripts/Runtime/Atmosphere.cs` | Knobs below; feeds the fog shader through shader globals every frame. Disabled/absent → fog pass is a pass-through. |
| Fog shader | `Unity/Assets/Atmosphere/Shaders/SevenHeightFog.shader` + `SevenHeightFog.mat` | One full-screen pass: ground fog layer + valley layer + height-thinned distance haze + in-fog glow sources. |
| Renderer feature | `SevenHeightFog` (Full Screen Pass) on `PC_Renderer` and `Mobile_Renderer` | Runs before transparents, so effects and UI stay crisp on top. Added by the builder. |
| Volume profile | `Unity/Assets/Atmosphere/Atmosphere_Volume.asset` | Heavy Bloom (threshold 0.85, intensity 1.5, scatter 0.78), saturation −100, contrast −8, Neutral tonemap, light vignette. |
| Noise | `Unity/Assets/Atmosphere/FogNoise.png` | Tileable grayscale noise for drifting ground-fog variation. |

All of it is (re)generated by `FightDemoBuilder.BuildAtmosphere()` — change the builder, not the assets by hand.

## Using it in a new world
1. Set scene `RenderSettings.fog = false` (the pass does the fog), flat ambient ~0.26, no skybox.
2. Instantiate `Atmosphere.prefab`.
3. Move the `Glow*` children to the bright spots of the world (scale.x = radius ×, scale.y = intensity ×; up to 8).
4. Make the foreground dark (albedo ~0.03–0.05) and the distant structures light (~0.6) with white emissive edges.
   Put distant structures so they rise out of the fog from below the horizon; the camera should see them across
   the ground-fog band.
5. The camera needs `requiresDepthTexture` on (the builder sets it).

## Knobs (`Atmosphere` component; defaults = the hill world)
| Knob | Default | Effect |
|---|---|---|
| `FogStart` | 5 m | No fog closer than this → foreground stays a dark silhouette. |
| `GroundDensity` / `GroundBase` / `GroundFalloff` | 0.07 /m, 0 m, 0.6 m | The thick layer hugging the walkable ground (legs vanish in it; the fog sea below a hill edge goes solid white). |
| `GroundRange` | 22 m | The ground layer only builds over this length of each view ray, so distant structures stay visible. |
| `ValleyDensity` / `ValleyBase` / `ValleyFalloff` | 0.002, −10 m, 15 m | Tall soft layer that buries the bases of distant structures. |
| `DistanceDensity` / `HazeHeight` | 0.0012 /m, 18 m | Low contrast with distance; thinner for rays that travel high (keeps the overhead mass dark). |
| `MaxFog` | 1 | Cap on fog opacity. |
| `NearBrightness` / `FarBrightness` / `BrightnessDistance` | 0.85, 0.95, 120 m | Fog brightness near → far (>1 blooms). |
| `ZenithBrightness` | 0.32 | Fog/sky brightness looking up (darker top like the reference). |
| `NoiseStrength` / `NoiseScale` / `NoiseSpeed` | 0.45, 0.035, 0.012 | Slow drifting variation in the ground layer. |
| `GlowIntensity` / `GlowRadius` | 0.35, 18 m | Soft light sources inside the fog (per-child scale multiplies them). |

**Tuning without rebuilding:** run the exe with `-atmofile <file.json>`, e.g.
`{"GroundDensity":0.05,"FarBrightness":1.1}` — any subset of the knob names above overrides the scene values.

## Cost (Steam Deck)
One full-screen pass with ~25 ALU ops + ≤8 glow terms per pixel and two noise samples; no ray marching, no volume
textures, no extra render targets beyond URP's depth copy. Bloom is the standard URP Bloom (high-quality filtering off).
Not yet profiled on a Deck.

## Variant: "from above" (Round 3 saucer)
`Unity/Assets/Atmosphere/Atmosphere_Above.prefab` — a prefab variant of `Atmosphere.prefab` for scenes that look *down*
on a world (the saucer hovers 200 m above the city; city ground at y = −200). Built by
`FightDemoBuilder.BuildAtmosphereAbove()`. Overrides:

| Knob | Value | Why |
|---|---|---|
| `FogStart` | 6 m | Keeps the ship interior clear. |
| `GroundDensity` / `GroundBase` / `GroundFalloff` / `GroundRange` | 0.03, −200 m, 22 m, 900 m | A thick fog sea hugging the city streets; long range because rays travel ~250 m down. |
| `ValleyDensity` / `ValleyBase` / `ValleyFalloff` | 0.006, −180 m, 55 m | Buries the tower bases; tops rise out of it. |
| `DistanceDensity` / `HazeHeight` | 0.0016, 40 m | Bright misty horizon around the ship. |
| `NearBrightness` / `FarBrightness` / `BrightnessDistance` / `ZenithBrightness` | 0.8, 1.02, 450 m, 0.34 | Glowing distance, darker sky overhead. |
| `NoiseScale` / `NoiseSpeed` / `NoiseFadeDistance` | 0.006, 0.004, 600 m | City-sized fog drift. |
| `GlowIntensity` / `GlowRadius` | 0.32, 60 m | `Glow*` children moved into the city clusters + one broad bright patch far out. |

The ship geometry uses `Seven/DissolveLit` (lit, double-sided, dissolvable) so the reveal can remove it; the fog pass
needs no changes for that (dissolved pixels simply show what is behind them).
